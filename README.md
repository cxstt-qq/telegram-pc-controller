# Remote PC Control

Telegram-бот для управления **основным Windows-ПК** из личного чата. Агент работает в открытом сеансе пользователя, соединяется с Telegram сам и не требует входящих портов. Доступ к командам имеет только `ALLOWED_USER_ID`.

## Возможности

- Скриншот, скриншот с координатной сеткой, увеличение участка через `/zoom X Y [размер]` и исходный PNG без сжатия Telegram. После `/click` и `/choose` место нажатия отмечено небольшим красным кругом без заливки.
- Список окон: активировать, свернуть, развернуть, закрыть. После действия бот обновляет текст и кнопки исходного сообщения со списком; страницы и кнопка «Обновить» работают в том же сообщении. При закрытии бот сначала даёт приложению выйти штатно; если окно исчезло, а его процесс остался в трее, завершает этот процесс. Список процессов: завершить по PID.
- В обычных списках скрыты служебные компоненты Windows и фоновые процессы NVIDIA. Для диагностики полный список доступен через `/windows all` и `/processes all`.
- Запуск файла, приложения или URI; избранные приложения в `apps.json`. `/apps` находит ярлыки рабочего стола и меню «Пуск», а также приложения из реестра меню «Пуск» Windows; `/apps слово` фильтрует их по названию и показывает кнопки запуска.
- Сценарии `/scenario start` и `/scenario stop` для фарма.
- ЛКМ, ПКМ, двойной клик, перетаскивание, прокрутка, ввод Unicode-текста, вставка через буфер обмена, клавиши и сочетания. После каждого действия с интерфейсом бот присылает новый скриншот.
- Поиск текста на экране через локальный Tesseract (русский и английский): найденные области нумеруются на скриншоте, координаты центра каждого совпадения выводятся текстом, выбор номера нажимает центр области. Строки с собственным `/find` бот пропускает; если текст мелкий и не найден, повторяет распознавание с увеличением. Работает и поверх окна RDP, если оно видно.
- Постоянная сессия `cmd.exe`: текущая папка и переменные сохраняются между сообщениями. Текстовый вывод, код завершения, тайм-аут и `/stop`.
- Статус ПК, громкость, перезагрузка, выключение, журнал действий.

## Установка

Требуется Windows 10/11 и Python 3.11 или новее. Для поиска текста нужен Tesseract OCR с языками `rus` и `eng` (если стоит в другом месте, укажите путь в `.env`).

1. Создайте бота через BotFather и сохраните его токен.
2. В PowerShell в этой папке запустите `./install.ps1`. Если политика PowerShell мешает запуску, используйте `powershell -ExecutionPolicy Bypass -File .\install.ps1`.
3. Откройте `.env`, внесите `TELEGRAM_BOT_TOKEN` и числовой `ALLOWED_USER_ID`. Если ID пока неизвестен, поставьте `ALLOWED_USER_ID=0`, запустите бота и отправьте ему `/id`. В этом режиме бот показывает только ID отправителя и не открывает управление. Затем впишите полученный ID и перезапустите бота.
4. Запустите `./.venv/Scripts/python.exe bot.py` и отправьте боту `/start` в личном чате.
5. Когда убедитесь, что бот отвечает и присылает скриншот, остановите ручной запуск (`Ctrl+C`) и запустите `./install_autostart.ps1` **в PowerShell от администратора**. Агент стартует после входа в Windows с повышенными правами. Для удаления задачи есть `./uninstall_autostart.ps1`.

Если задача уже была установлена без повышения прав, один раз запустите `./enable_farm_access.ps1` в PowerShell от администратора. Проверка: `/status` в Telegram должен показывать «Права бота: администратор». После повышения прав `/cmd` также выполняется от администратора.

Токен хранится локально в `.env`; файл исключён из Git. Не пересылайте его в чат. Рабочие логи лежат в `logs/`. Команды, включая `cmd`, могут содержать чувствительные данные и записываются в журнал.

## Прокси для Telegram

В `.env` заполните `TELEGRAM_PROXY_URL`. Поддерживаются HTTP(S) и SOCKS5. Примеры:

```text
TELEGRAM_PROXY_URL=socks5h://127.0.0.1:1080
TELEGRAM_PROXY_URL=http://user:password@proxy.example:8080
```

Выберите **одну** строку. Для SOCKS рекомендуем `socks5h`: имя `api.telegram.org` разрешается на стороне прокси. У `socks5` DNS-запрос выполняется на самом ПК. Если в логине или пароле есть `@`, `#`, `:` или пробелы, закодируйте их как URL-компоненты. Прокси используется для всех вызовов Telegram API, включая отправку изображений; если он недоступен, бот ждёт восстановления и не переключается на прямое соединение. Локальный прокси на `127.0.0.1` должен запускаться автоматически раньше бота.

После изменения `.env` перезапустите бота и проверьте маршрут:

```powershell
.\.venv\Scripts\python.exe bot.py --check
```

Команда покажет имя бота и сообщит, доступен ли Telegram через указанный прокси. Она не выводит токен или пароль прокси.

## Использование

Главное меню — `/start` или `/menu`. Кнопки открывают разделы или запрашивают аргументы следующим сообщением. `/help` показывает все команды.

Примеры:

```text
/screen
/screen grid
/screen file
/zoom 1850 1020 300
/windows
/windows all
/processes
/processes all
/window activate 123456
/window minimize 123456
/window maximize 123456
/window close 123456
/apps Roblox
/scenario start
/scenario stop
/click 850 420
/click right 850 420
/move 1850 1020
/scroll -4 850 420
/text Привет, мир!
/paste Привет, мир!
/clipboard
/key enter
/key ctrl+c
/keys
/find Подключиться
/choose 1
/cmd
cd /d "C:\Program Files"
dir
/cmd off
/launch C:\Windows\System32\notepad.exe
/status
/stop
```

Координаты задаются в **исходных пикселях экрана** (размер указан в подписи к скриншоту). Для иконок без текста используйте `/screen grid`, затем `/zoom X Y` для участка около иконки. Сетка приближения размечена через 50 исходных пикселей. `/move X Y` наведёт курсор и через секунду пришлёт скриншот с подсказкой, если приложение её показывает. После `/click` красный круг на скриншоте отмечает место нажатия. Для RDP сначала активируйте его окно. При изменении масштаба или расположения окна снова отправьте `/find`: старые координаты могут стать неверными. OCR не гарантирует распознавание стилизованного текста; можно воспользоваться сеткой и кликом по координатам. Некоторые игры, защищённые окна и экран UAC могут не принимать обычный ввод.

`/key` принимает одну клавишу или сочетание до пяти клавиш через `+`: например `/key f5`, `/key alt+f4`, `/key ctrl+shift+s`. Поддерживаются F1–F24, A–Z, 0–9, `ctrl`, `shift`, `alt`, `win`, `enter`, `esc`, `tab`, `space`, `backspace`, `delete`, `insert`, `home`, `end`, `pageup`, `pagedown`, стрелки `up/down/left/right`, `printscreen`, `pause`, `volumeup`, `volumedown`, `mute`. Список можно запросить у бота через `/keys`.

`/window close HWND` ждёт до 3 секунд. Если окно всё ещё видно (например, приложение спрашивает о сохранении), процесс остаётся работать, а бот пришлёт скриншот с запросом. Процессы оболочки Windows, включая `explorer.exe`, бот после закрытия окна не завершает: они обслуживают рабочий стол. `/kill PID` остаётся доступной явной командой.

`/cmd` включает постоянную скрытую CMD-сессию с правами текущего пользователя Windows. Пока она включена, обычные текстовые сообщения исполняются в ней; команды бота с `/` продолжают работать. `/cmd команда` тоже отправляет команду в эту сессию и включает её, если нужно. `/cmd off` или кнопка «Завершить CMD» закрывает процесс; `/stop` останавливает выполняемую команду и завершает сессию. Для путей с пробелами нужны кавычки, например `cd /d "C:\Program Files"`. Максимальное время одной команды задаётся `CMD_TIMEOUT_SECONDS` (по умолчанию 120 секунд); вывод ограничен 45 000 символами для Telegram. Команда `exit` также завершит сессию. Запросы, пришедшие пока бот был выключен, удаляются при новом запуске, чтобы они не исполнились неожиданно.

В `apps.json` можно добавить избранное:

```json
{
  "Блокнот": "C:\\Windows\\System32\\notepad.exe",
  "RDP": "C:\\Windows\\System32\\mstsc.exe"
}
```

Перезагрузка и выключение требуют подтверждения кнопкой. После перезагрузки управление окнами станет доступно после автоматического входа в учётную запись и запуска агента.

## Сценарии

`/scenario start` закрывает видимые программы, сохраняя Potassium и Roblox Account Manager, затем запускает `general (ALT9).bat` из `AppData\Local\zapret-discord-youtube-1.9.5` и `farm_zapzonex.bat` из `Documents\Roblox_fix\yba\v3\zapzonex`. `/scenario stop` завершает процессы фарма и Zapret, закрывает остальные видимые программы и сохраняет RAM. Оболочка Windows, сам бот и процесс локального Telegram-прокси также сохраняются, чтобы удалённое управление осталось доступным.

Сценарии требуют повышенных прав: батник фарма сам проверяет права администратора. Перед закрытием приложений бот проверяет наличие обоих батников и свои права. Если приложение не закрывается штатно, сценарий принудительно завершает процесс, включая окна с несохранёнными изменениями. **Не запускайте сценарии для проверки на рабочем столе с нужными несохранёнными данными.** Файл `general (ALT9).bat` содержит пробел перед скобкой; бот использует это фактическое имя.
